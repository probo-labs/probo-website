### Running in CI/CD
To integrate your test suite into a CI/CD pipeline:
* Open the context menu for the specific test suite.
* Select the **CI/CD** option to receive setup instructions.
<img src="/images/screenshots/test-suite-context-menu.png" alt="Test suite context-menu" width="300" />

> **Note:** All scenarios in a suite must belong to the same project. If you move a scenario to a different project, it will be automatically removed from the test suite.
