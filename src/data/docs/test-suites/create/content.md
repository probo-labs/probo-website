### Creating a Test Suite

1. Click the **Suites** button in the bottom toolbar of the application. The **Test suites** tab will open.
<img src="/images/screenshots/test-suite.png" alt="Test suite button" width="300" />
2. Click **New test suite**.
<img src="/images/screenshots/new-test-suite.png" alt="New test suite button" width="200" />
3. Enter a name for your suite.
4. Select the **Project** containing the scenarios you want to include.
6. Select the scenarios you want to add.
7. Save your selection.
<img src="/images/screenshots/create-test-suite.png" alt="Create suite button" width="600" />
