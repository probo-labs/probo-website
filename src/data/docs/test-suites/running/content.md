### Running a Test Suite from the Interface
1. Open the **Suites** section and locate your suite under the **ALL TEST SUITES** menu.
<img src="/images/screenshots/test-suite-in-list.png" alt="Test suite in list" width="300" />
2. Click the **Run** icon next to the desired suite.
3. A new entry will appear in the execution list. Click it to monitor real-time progress.
4. Once finished, click **View report** to open a detailed report of the test results.
<img src="/images/screenshots/test-suite-run-result.png" alt="Test suite run result" width="800" />
